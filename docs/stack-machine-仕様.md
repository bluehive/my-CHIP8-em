# マイクロスタックマシン仕様

Racket で **コードファイル 1 つ** に収まる学習用スタック機械である。
CHIP-8 の仕様・命令・メモリマップとは独立する。この文書はスタック機械だけを定める。
同じリポジトリの CHIP-8 文書と命令・メモリを共用しない。

段階の切り方（lesson1..6 で機能を足す）だけ [pbohun/stack-vm-tutorials の stack-vm-lessons](https://github.com/pbohun/stack-vm-tutorials/tree/master/stack-vm-lessons) を参照する。命令エンコード・メモリモデル・アセンブラは非採用である。オペコード表は転載しない。

各レッスンは、そこに書いたトークン集合だけを仕様とする。集合外は対象外であり、そのレッスンの例に書かない。完成機のエラー意味はレッスン 5 以降に一本化する。実装コードはこの文書に書かない。

プログラムは後置のトークン列である。数字は積む。語は演算する。仕様上の語は大文字に固定する（`HALT` `ADD` …）。小文字はレッスン 5 の未知語である。

## 全体の目的

- オペランドはレジスタではなくスタック頂点から取る
- 1 サイクルは「1 トークンを読む → 実行」
- GUI・ファイル ROM・アセンブラは持たない

## レッスン 1 — 状態とサイクルと HALT

置いてよいトークン: `HALT` のみ。整数も他の語も対象外。

### 定数

- プログラムはトークンのリスト 1 本
- PC はそのリストの添字。初期値 0
- スタック深さは設けない
- レジスタは無い
- ラベルは無い

### 状態

1 か所に次だけ置く。

- `program` — トークン列
- `pc` — 次に読む添字
- `stack` — データスタック（右が頂点）
- `halt?` — 停止

### 実行

開始時は `pc = 0`、スタック空、`halt?` は偽。

毎サイクル:

1. `halt?` が真なら停止する
2. フェッチ前に `pc` がリスト長以上なら停止する（HALT 無しで末尾に達した）。この停止はフェッチ前に限る
3. `program[pc]` を読む
4. このレッスンまでに定めたとおり実行する

### このレッスンのトークン

| トークン | スタック（前 → 後） | PC | 意味 |
|---|---|---|---|
| `HALT` | 不変 | 止め | `halt?` を真にする |

### 合格例

添字は左から 0 である。

- `()` → 停止。スタック空。トークンは読まない
- `(HALT)` → 停止。スタック空
- `(HALT HALT)` → 先頭の `HALT` で停止。2 つ目は読まない

## レッスン 2 — 整数（PUSH）

置いてよいトークン: 整数と `HALT`。

整数 `n` を読むと、それを積む。語 `PUSH` は置かない。整数そのものが PUSH である。値は Racket の整数で、幅は設けない。

| トークン | スタック（前 → 後） | PC | 意味 |
|---|---|---|---|
| 整数 `n` | … → … n | +1 | 積む |

`HALT` はレッスン 1 のまま。

### 合格例

- `(3 HALT)` → 停止時のスタック頂点 3、要素は 1 つ
- `(3 4 HALT)` → 頂点 4、要素は 2 つ（右が頂点）
- `(HALT 99)` → 先頭で停止。`99` は実行しない。スタック空

## レッスン 3 — ADD と SUB

置いてよいトークン: 整数、`HALT`、`ADD`、`SUB`。

頂点が右オペランドである。合格例はスタックに 2 つある列だけにする。足りない列はこのレッスンの対象外である。

| トークン | スタック（前 → 後） | PC | 意味 |
|---|---|---|---|
| `ADD` | … a b → … (a+b) | +1 | 頂点が右オペランド |
| `SUB` | … a b → … (a−b) | +1 | 頂点が減数 |

### 合格例

- `(3 4 ADD HALT)` → 停止時のスタック頂点 7、要素は 1 つ
- `(5 2 SUB HALT)` → 頂点 3（計算は 5−2）
- `(3 4 ADD)` → 末尾で停止。頂点 7（HALT 無し）

## レッスン 4 — POP DUP SWAP

置いてよいトークン: 整数、`HALT`、`ADD`、`SUB`、`POP`、`DUP`、`SWAP`。

合格例は必要数が揃った列だけにする。空の `POP` と足りない列はこのレッスンの対象外である。

| トークン | スタック（前 → 後） | PC | 意味 |
|---|---|---|---|
| `POP` | … a → … | +1 | 捨てる |
| `DUP` | … a → … a a | +1 | 頂点を複製 |
| `SWAP` | … a b → … b a | +1 | 頂点 2 つを入れ替え |

### 合格例

- `(10 DUP ADD HALT)` → 頂点 20
- `(1 2 SWAP SUB HALT)` → 頂点 1（計算は 2−1）
- `(3 4 POP HALT)` → 頂点 3、要素は 1 つ

## レッスン 5 — エラー（空 pop と未知語）

置いてよいトークン: 整数と `HALT` `ADD` `SUB` `POP` `DUP` `SWAP`。ここから、集合外をプログラムに置いたときの意味を定める。

エラーは即停止する。回復しない。

- 未知の語はエラーである（語 `PUSH`、小文字、`JMP` も含む。このレッスンでは `JMP` はまだ未知語である）
- `POP` / `DUP` はスタックが 1 未満、`SWAP` / `ADD` / `SUB` は 2 未満ならエラーである
- 空スタックの `POP` はエラーである

`JMP` の番地検査はこのレッスンでは定めない。

### 不合格例

- `(POP)` → エラー（空）
- `(DUP)` → エラー（空）
- `(ADD HALT)` → エラー（足りない）
- `(1 ADD HALT)` → エラー（足りない）
- `(1 SWAP HALT)` → エラー（足りない）
- `(PUSH 1 HALT)` → エラー（未知語 `PUSH`）
- `(FOO)` → エラー（未知語）
- `(halt)` → エラー（未知語。仕様の語は大文字）
- `(JMP 0)` → エラー（このレッスンでは未知語 `JMP`）

## レッスン 6 — JMP

置いてよいトークン: レッスン 5 までと `JMP`。

| トークン | スタック（前 → 後） | PC | 意味 |
|---|---|---|---|
| `JMP` | 不変 | 成功時はその番地 | 次のトークンを番地として消費し、積まない。成功したときだけ PC をその添字にする |

成功条件は次をすべて満たすことだけである。

- 次のトークンが存在する
- それが整数である
- `0 ≤ 番地 < リスト長`

失敗は即エラーである。失敗した PC を代入してからフェッチ前停止に任せない。末尾停止（フェッチ前に `pc ≥ 長さ`）と JMP の範囲外エラーは別である。

番地はラベルではなく、トークン列の添字（0 始まり）である。相対ジャンプは無い。

`(JMP 0)` は無限ループになり得る。検証ではサイクル上限で切ってよい。上限は機械の状態に含めない。

### 合格例

- `(JMP 3 99 4 5 ADD HALT)` → `99` を飛ばし、4 と 5 を足して頂点 9

### 回帰

- `(HALT 99 JMP)` → 先頭で停止。`99` も `JMP` も実行しない（レッスン 1 の HALT）

### 挙動

- `(JMP 0)` → 番地 0 へ飛ぶ。無限ループ

### 不合格例

- `(JMP HALT)` → エラー（番地が整数でない）
- `(JMP)` → エラー（次のトークンが無い）
- `(JMP 99)` → エラー（範囲外）
- `(JMP -1)` → エラー（範囲外）

## 制約

プログラムは Racket のリストリテラルで書く。アセンブラ・パーサ・モジュール分割は含めない。

## この仕様に無いもの

- メモリ、画面、キー、タイマ
- 呼び出しスタック、`CALL` / `RET`
- バイトコード、命令番号、i32 パック命令
- 乗除、ビット演算、比較、条件 JMP
- ラベル名
- CHIP-8 の命令とメモリマップ

必要になったら別仕様にする。今の 1 ファイルには入れない。
