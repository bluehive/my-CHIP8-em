# CHIP-8 命令セット（日本語訳）

このファイルは Matthew Mikolay の CHIP-8 命令セット解説の日本語訳です。[1]
原文は 2019-11-02 編集、リビジョン 3 です。[1]

**注意: 原文は [Creative Commons Attribution-ShareAlike 4.0](http://creativecommons.org/licenses/by-sa/4.0/) の下でライセンスされています。**[1][2]
本訳も同じライセンスです（改変あり: 日本語への翻訳）。

CHIP-8 命令セットの 35 命令を次の表に示します。[1]
`NNN` は 16 進のメモリアドレス、`NN` は 16 進の 1 バイト、`N` は 16 進のニブル（4 ビット）を指します。[1]
`X` と `Y` はレジスタを指します。[1]

| 命令 | 説明 |
|---|---|
| `0NNN` | アドレス `NNN` の機械語サブルーチンを実行する |
| `00E0` | 画面をクリアする |
| `00EE` | サブルーチンから戻る |
| `1NNN` | アドレス `NNN` へジャンプする |
| `2NNN` | アドレス `NNN` から始まるサブルーチンを実行する |
| `3XNN` | レジスタ `VX` の値が `NN` と等しいなら、次の命令をスキップする |
| `4XNN` | レジスタ `VX` の値が `NN` と等しくないなら、次の命令をスキップする |
| `5XY0` | レジスタ `VX` の値がレジスタ `VY` の値と等しいなら、次の命令をスキップする |
| `6XNN` | 数値 `NN` をレジスタ `VX` に格納する |
| `7XNN` | 値 `NN` をレジスタ `VX` に加算する |
| `8XY0` | レジスタ `VY` の値をレジスタ `VX` に格納する |
| `8XY1` | `VX` を `VX` OR `VY` にする |
| `8XY2` | `VX` を `VX` AND `VY` にする |
| `8XY3` | `VX` を `VX` XOR `VY` にする |
| `8XY4` | レジスタ `VY` の値をレジスタ `VX` に加算する。キャリーが起きたら `VF` を `01` にする。キャリーが起きなければ `VF` を `00` にする |
| `8XY5` | レジスタ `VX` からレジスタ `VY` の値を減算する。ボローが起きたら `VF` を `00` にする。ボローが起きなければ `VF` を `01` にする |
| `8XY6` | レジスタ `VY` を 1 ビット右シフトした値をレジスタ `VX` に格納する¹。シフト前の最下位ビットをレジスタ `VF` に格納する。`VY` は変更しない |
| `8XY7` | レジスタ `VX` を、`VY` から `VX` を引いた値にする。ボローが起きたら `VF` を `00` にする。ボローが起きなければ `VF` を `01` にする |
| `8XYE` | レジスタ `VY` を 1 ビット左シフトした値をレジスタ `VX` に格納する¹。シフト前の最上位ビットをレジスタ `VF` に格納する。`VY` は変更しない |
| `9XY0` | レジスタ `VX` の値がレジスタ `VY` の値と等しくないなら、次の命令をスキップする |
| `ANNN` | メモリアドレス `NNN` をレジスタ `I` に格納する |
| `BNNN` | アドレス `NNN + V0` へジャンプする |
| `CXNN` | マスク `NN` を掛けた乱数を `VX` に設定する |
| `DXYN` | 位置 `VX`, `VY` に、レジスタ `I` に格納されたアドレスから始まる `N` バイトのスプライトデータを描画する。セットされていた画素がアンセットに変わった場合は `VF` を `01` にし、そうでなければ `00` にする |
| `EX9E` | レジスタ `VX` に現在格納されている 16 進値に対応するキーが押されていれば、次の命令をスキップする |
| `EXA1` | レジスタ `VX` に現在格納されている 16 進値に対応するキーが押されていなければ、次の命令をスキップする |
| `FX07` | ディレイタイマの現在値をレジスタ `VX` に格納する |
| `FX0A` | キー入力を待ち、結果をレジスタ `VX` に格納する |
| `FX15` | ディレイタイマをレジスタ `VX` の値に設定する |
| `FX18` | サウンドタイマをレジスタ `VX` の値に設定する |
| `FX1E` | レジスタ `VX` に格納された値をレジスタ `I` に加算する |
| `FX29` | レジスタ `VX` に格納された 16 進数字に対応するスプライトデータのメモリアドレスを `I` に設定する |
| `FX33` | レジスタ `VX` に格納された値の [二進化十進数](https://en.wikipedia.org/wiki/Binary-coded_decimal) 相当を、アドレス `I`、`I + 1`、`I + 2` に格納する |
| `FX55` | レジスタ `V0` から `VX` まで（両端を含む）の値を、アドレス `I` から始まるメモリに格納する。操作後、`I` は `I + X + 1` になる² |
| `FX65` | アドレス `I` から始まるメモリの値で、レジスタ `V0` から `VX` まで（両端を含む）を埋める。操作後、`I` は `I + X + 1` になる² |

表の各行の意味は原文の 35 命令表に対応します。[1]

## 注

¹ [Erik Bryntse の S-CHIP 文書](http://devernay.free.fr/hacks/chip8/schip.txt) は、このシフト命令を `VY` ではなく `VX` をシフトすると誤って説明しています。[1][3]
S-CHIP 互換のエミュレータの一部は、その説明どおりに実装していることがあります。[1]

² [Erik Bryntse の S-CHIP 文書](http://devernay.free.fr/hacks/chip8/schip.txt) は、この命令が `I` レジスタを変更しないと誤って示唆しています。[1][3]
S-CHIP 互換のエミュレータの一部は、その説明どおりに実装していることがあります。[1]
