# テスト例（14）

完成機（レッスン 6 まで）向けの例である。実装は利用者が書く。ここにあるのは **入力のトークン列と、停止時のスタック（またはエラー）** だけである。

図は右が頂点。語 `PUSH` は使わない。トレースは仕様の規則で手計算し、別環境のスクラッチで照合した。

合格 1〜10、不合格 11〜14。

## 1. 空プログラム

プログラム: `()`

期待: 停止。スタック `[]`。トークンは読まない（フェッチ前の末尾停止）。

```
  []     ← 読まずに停止
```

## 2. 停止だけ

プログラム: `(HALT)`

期待: 停止。スタック `[]`。

```
  []     → HALT
  []
```

## 3. 整数を 1 つ積む

プログラム: `(3 HALT)`

期待: 頂点 3、要素 1。

```
  []          → 整数 3 を積む
  [3]         → HALT
  [3]
```

## 4. 整数を 2 つ積む

プログラム: `(3 5 HALT)`

期待: 頂点 5、要素 2。

```
  []          → 3
  [3]         → 5
  [3, 5]      → HALT
  [3, 5]
```

## 5. ADD（3+5）

プログラム: `(3 5 ADD HALT)`

期待: 頂点 8、要素 1。

```
  []          → 3
  [3]         → 5
  [3, 5]      → ADD（a=3, b=5, 3+5）
  [8]         → HALT
  [8]
```

## 6. SUB（5−2）

プログラム: `(5 2 SUB HALT)`

期待: 頂点 3、要素 1。

```
  []          → 5
  [5]         → 2
  [5, 2]      → SUB（a=5, b=2, 5-2）
  [3]         → HALT
  [3]
```

## 7. DUP して足す

プログラム: `(10 DUP ADD HALT)`

期待: 頂点 20。

```
  []          → 10
  [10]        → DUP
  [10, 10]    → ADD
  [20]        → HALT
  [20]
```

## 8. SWAP して引く

プログラム: `(1 2 SWAP SUB HALT)`

期待: 頂点 1（計算は 2−1）。

```
  []          → 1
  [1]         → 2
  [1, 2]      → SWAP
  [2, 1]      → SUB（a=2, b=1）
  [1]         → HALT
  [1]
```

## 9. POP

プログラム: `(3 4 POP HALT)`

期待: 頂点 3、要素 1。

```
  []          → 3
  [3]         → 4
  [3, 4]      → POP
  [3]         → HALT
  [3]
```

## 10. JMP で飛ばす

プログラム: `(JMP 3 99 4 5 ADD HALT)`

添字: `0:JMP 1:3 2:99 3:4 4:5 5:ADD 6:HALT`

期待: 99 は実行しない。頂点 9。

```
  []          → JMP 3（pc=3。99 は積まない）
  []          → 4
  [4]         → 5
  [4, 5]      → ADD
  [9]         → HALT
  [9]
```

## 11. 空 POP（不合格）

プログラム: `(POP)`

期待: エラー（空）。

```
  []     → POP → エラー
```

## 12. ADD 不足（不合格）

プログラム: `(1 ADD HALT)`

期待: エラー（2 枚無い）。HALT には到達しない。

```
  []          → 1
  [1]         → ADD → エラー
```

## 13. 語 PUSH（不合格）

プログラム: `(PUSH 1 HALT)`

期待: エラー（未知語）。整数 1 は読まない。

```
  []     → PUSH → エラー
```

## 14. JMP の負番地（不合格）

プログラム: `(JMP -1)`

期待: エラー（範囲外）。成功条件は `0 ≤ 番地 < 長さ` だけである。

```
  []     → JMP -1 → エラー
```
