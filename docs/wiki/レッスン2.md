# レッスン2 — 整数を積む

置いてよいトークン: 整数と `HALT`。

正本: 仕様のレッスン 2。

## 「積む」とは

スタックの頂点（右端）に値を 1 つ足すことである。多くの教科書はこれを Push と呼ぶ。**この機械のプログラムには語 `PUSH` を書かない。** 整数トークンそのものが、積む操作である。

`(3 HALT)` は「3 を積んで止まる」である。`PUSH` という語は、完成機では未知語エラーになる（[[レッスン5]]）。

値は Racket の整数である。ビット幅は設けない。

## 右が頂点

図の右端が「今使える値」である。左へ行くほど古い。

```
命令列: (3 5 HALT)

スタックの変化（右が頂点）:
  []          → 整数 3 を積む（pc は 0 から 1 へ）
  [3]         → 整数 5 を積む（pc は 1 から 2 へ）
  [3, 5]      → HALT
  [3, 5]      ← 停止。頂点は 5、要素は 2 つ
```

PC との対応:

```
プログラム: (3 5 HALT)
添字:        0 1  2

pc=0 で 3 を読む → 積む → pc=1
pc=1 で 5 を読む → 積む → pc=2
pc=2 で HALT を読む → 停止
```

整数を実行したあと、pc は必ず 1 進む。

## HALT の後ろは実行しない

停止フラグが真なら、その先の整数は読まない。スタックは空のままである。

```
命令列: (HALT 99)

スタックの変化:
  []     → HALT
  []     ← 停止。99 は積まない
```

## 合格例

- `(3 HALT)` → 頂点 3、要素 1
- `(3 4 HALT)` → 頂点 4、要素 2
- `(HALT 99)` → スタック空。99 は実行しない
