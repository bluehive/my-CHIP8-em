# レッスン4 — POP DUP SWAP

置いてよいトークン: 整数、`HALT`、`ADD`、`SUB`、`POP`、`DUP`、`SWAP`。

正本: 仕様のレッスン 4。足りない列はこのレッスンの対象外。

スタック操作の基本は 3 つだけである。どれも **頂点側** だけを触る。pc は実行後に 1 進む。

## POP とは

頂点を 1 つ捨てる。結果は積まない。

```
命令列: (3 4 POP HALT)

スタックの変化（右が頂点）:
  []          → 3
  [3]         → 4
  [3, 4]      → POP（頂点 4 を捨てる）
  [3]         → HALT
  [3]         ← 頂点 3、要素 1
```

## DUP とは

頂点を複製して積む。同じ値が 2 つ並ぶ。

```
命令列: (10 DUP ADD HALT)

  []          → 10
  [10]        → DUP
  [10, 10]    → ADD（10+10）
  [20]        → HALT
  [20]        ← 頂点 20
```

「同じ数を 2 回書く」代わりに、一度積んで複製できる。

## SWAP とは

頂点 2 つを入れ替える。要素数は変わらない。

SUB の前に使うと、減数と被減数を入れ替えられる。

```
命令列: (1 2 SWAP SUB HALT)

  []          → 1
  [1]         → 2
  [1, 2]      → SWAP
  [2, 1]      → SUB（a=2, b=1, 2-1）
  [1]         → HALT
  [1]         ← 頂点 1
```

SWAP しなければ `(1 2 SUB)` は 1−2 で −1 になる。

## 合格例

- `(10 DUP ADD HALT)` → 頂点 20
- `(1 2 SWAP SUB HALT)` → 頂点 1
- `(3 4 POP HALT)` → 頂点 3、要素 1
