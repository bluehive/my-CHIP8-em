# レッスン6 — JMP

置いてよいトークン: レッスン 5 までと `JMP`。

正本: 仕様のレッスン 6。

## JMP とは

次のトークンを **飛び先の添字** として読み、PC をそこへ移す語である。スタックは触らない。飛び先の整数はスタックに積まない。

成功条件は次をすべて満たすことだけである。

1. 次のトークンが存在する
2. それが整数である
3. `0 ≤ 番地 < リスト長`

失敗は即エラーである。失敗した PC を代入してから、レッスン 1 の末尾停止に任せてはいけない。

- 末尾停止: **フェッチ前** に pc が長さ以上
- JMP の範囲外: **JMP を実行した時点** で番地を拒否

ラベル名は無い。相対ジャンプは無い。番地はリストの添字である。

## PC が飛び先になる流れ

```
プログラム: (JMP 3 99 4 5 ADD HALT)
添字:        0   1  2  3 4  5   6
```

1. pc=0 で JMP を読む
2. 次のトークンは添字 1 の整数 3。`0 ≤ 3 < 7` なので成功
3. 3 は積まない。pc を 3 にする
4. 添字 2 の 99 は飛ばされる
5. pc=3 で 4 を積む、pc=4 で 5 を積む、ADD、HALT

```
命令列: (JMP 3 99 4 5 ADD HALT)

スタックの変化（右が頂点）:
  []          → JMP 3（pc を 3 へ。99 は読まない）
  []          → 整数 4 を積む
  [4]         → 整数 5 を積む
  [4, 5]      → ADD
  [9]         → HALT
  [9]         ← 頂点 9
```

## 無限ループ

`(JMP 0)` は番地 0 へ飛ぶ。また JMP を読む。検証ではサイクル回数の上限で切ってよい。上限は機械の状態に含めない。

## 回帰

`(HALT 99 JMP)` は先頭の HALT で止まる。99 も JMP も実行しない。レッスン 1 の確認である。

## 合格例

- `(JMP 3 99 4 5 ADD HALT)` → 頂点 9

## 不合格例

- `(JMP HALT)` → 次が整数でない
- `(JMP)` → 次のトークンが無い
- `(JMP 99)` → 範囲外
- `(JMP -1)` → 範囲外（負も不可）
