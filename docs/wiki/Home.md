## この機械は何か

計算の材料をレジスタに置かない。材料は **スタック** の頂点から取る。プログラムは後置のトークン列である。数字は積む。語は演算する。

語 `PUSH` は置かない。整数そのものが「積む」である。仕様上の語は大文字に固定する（`ADD` `HALT` …）。

## スタックとは

スタックは縦に積む皿である。新しく置いたものが頂点（右端）になる。演算は頂点から必要な枚数を取り、結果をまた頂点へ戻す。

深さの上限は設けない。空なのに取ろうとすると、完成機ではエラーで止まる（[[レッスン5]]）。

図は常に **右が頂点** とする。

```
命令列: (3 5 ADD)

スタックの変化（右が頂点）:
  []          → 整数 3 を積む
  [3]         → 整数 5 を積む
  [3, 5]      → ADD（5 と 3 を取り、3+5 を積む）
  [8]         ← 結果
```

## PC とは

PC（プログラムカウンタ）は、「次に読むトークン」の場所である。この機械ではメモリ番地ではなく、**トークン列の添字** である。左端が 0。開始時は 0。

```
プログラム: (3 5 ADD HALT)
添字:        0  1  2    3
             ^
            pc=0 のとき、次に読むのは 3
```

1 サイクルは次だけをする。

1. すでに停止なら終わる
2. フェッチ前に pc が列の長さ以上なら終わる（末尾）
3. `program[pc]` を 1 つ読む
4. そのトークンどおり実行する（多くの語は実行後に pc を 1 進める）

「1 サイクルで 1 トークン」である。バイト列をデコードしない。

## 状態（4 つだけ）

- `program` — トークン列
- `pc` — 次に読む添字
- `stack` — データスタック（右が頂点）
- 停止フラグ — 真ならもう読まない

レジスタもラベルもメモリも無い。
