# レッスン5 — エラー（空 pop と未知語）

置いてよいトークン: 整数と `HALT` `ADD` `SUB` `POP` `DUP` `SWAP`。ここから、集合外を置いたときの意味を定める。

正本: 仕様のレッスン 5。

## エラーとは

機械が **即停止** することである。回復しない。スタックを直して続きを読まない。

レッスン 1〜4 の合格例は、置いてよいトークンだけで、しかもスタックが足りている列だった。完成機では、次をエラーにする。

## 未知語

仕様に無い語はエラーである。

- 語 `PUSH`（整数そのものが積む操作なので、この語は存在しない）
- 小文字（`halt` など。仕様の語は大文字だけ）
- このレッスンでは `JMP` もまだ未知語である（意味は [[レッスン6]]）

```
命令列: (PUSH 1 HALT)

  []     → 語 PUSH を読む → エラー（未知語）
```

整数 1 には到達しない。

## 空 pop と不足

頂点から取る枚数が足りないときもエラーである。

- `POP` / `DUP` は 1 枚必要
- `SWAP` / `ADD` / `SUB` は 2 枚必要
- 空スタックの `POP` はエラー

```
命令列: (POP)

  []     → POP → エラー（空）
```

```
命令列: (1 ADD HALT)

  []          → 1
  [1]         → ADD → エラー（2 枚無い）
```

ADD は b と a が揃って初めて足せる。1 枚では足せない。

## JMP の番地検査はまだしない

`(JMP 0)` をこのレッスンで置くと、未知語 `JMP` でエラーになる。番地が範囲外かどうかは見ない。番地の規則は [[レッスン6]] だけが定める。

## 不合格例

- `(POP)` → 空
- `(DUP)` → 空
- `(ADD HALT)` → 足りない
- `(1 ADD HALT)` → 足りない
- `(1 SWAP HALT)` → 足りない
- `(PUSH 1 HALT)` → 未知語 `PUSH`
- `(FOO)` → 未知語
- `(halt)` → 未知語（大文字ではない）
- `(JMP 0)` → このレッスンでは未知語 `JMP`
