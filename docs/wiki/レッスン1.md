# レッスン1 — 状態とサイクルと停止

置いてよいトークン: 停止の語だけ。整数も他の語も、このレッスンでは対象外。

正本: [`docs/stack-machine-仕様.md`](https://github.com/bluehive/my-CHIP8-em/blob/main/docs/stack-machine-%E4%BB%95%E6%A7%98.md) のレッスン 1。

## PC とは（もう一度）

PC は Program Counter の略で、**次に実行する命令の位置** を指す。CPU の説明でよく出る言葉だが、この機械では次の意味に限定する。

- 指す先は RAM のバイト番地ではない
- 指す先は **トークンリストの何番目か**（0 始まりの添字）
- 開始時は必ず 0
- 「今どこを読んでいるか」が PC で、「皿の山」がスタックである。二つは別物

```
プログラム: (HALT HALT)
添字:        0     1
pc=0 → 先頭の HALT を読む → 停止フラグを真にする
2 つ目の HALT は読まない
```

## サイクルとは

時計の 1 目盛りで、機械がすることの単位である。この機械の 1 サイクルは「トークンを 1 個読む → 実行」だけである。

開始時:

- pc = 0
- スタックは空 `[]`
- 停止フラグは偽

毎サイクルの順番（この順を入れ替えない）:

1. 停止フラグが真なら、何も読まず終わる
2. **フェッチ前** に pc がリスト長以上なら終わる（HALT が無くても末尾で止まる）
3. `program[pc]` を読む
4. そのトークンの規則どおり実行する

末尾停止は「読む前」に判定する。JMP（[[レッスン6]]）で範囲外の番地を入れたエラーとは別である。

## 状態は 4 つ

全部 1 か所に置く。

| 名前 | 役割 |
|---|---|
| program | トークン列そのもの |
| pc | 次に読む添字 |
| stack | データ。右が頂点 |
| 停止フラグ | 真ならサイクル 1 で終わる |

レジスタは無い。ラベルは無い。画面もキーも無い。

## HALT とは

「もう読まない」と宣言する語である。スタックは触らない。pc を進める必要は無い。停止フラグを真にすれば、次のサイクルの先頭で終わる。

```
命令列: (HALT)

スタックの変化（右が頂点）:
  []     → HALT
  []     ← 停止。何も積んでいない
```

空のプログラム `()` はトークンが 0 個である。開始直後、pc=0 は長さ 0 以上なので、フェッチ前停止になる。HALT を読まない。

```
命令列: ()

スタックの変化:
  []     ← 読まずに停止
```

## 合格例

- `()` → 停止。スタック空。トークンは読まない
- `(HALT)` → 停止。スタック空
- `(HALT HALT)` → 先頭で停止。2 つ目は読まない
