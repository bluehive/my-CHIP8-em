# レッスン3 — ADD と SUB

置いてよいトークン: 整数、`HALT`、`ADD`、`SUB`。

正本: 仕様のレッスン 3。足りないスタックの列は、このレッスンの対象外（エラーは [[レッスン5]]）。

## ADD とは

頂点から値を 2 つ取り、足して、結果を 1 つ積む語である。

取り方は決まっている。

- 頂点（右）が **b**（右オペランド）
- その下（左）が **a**
- 積む値は **a + b**
- 実行後、pc は 1 進む

後置なので、プログラム上は「材料、材料、演算」の順になる。`(3 5 ADD)` は中置の 3+5 に相当する。

```
命令列: (3 5 ADD)

スタックの変化（右が頂点）:
  []          → 整数 3 を積む
  [3]         → 整数 5 を積む
  [3, 5]      → ADD（b=5, a=3, 3+5）
  [8]         ← 結果
```

HALT を付けた完成形:

```
命令列: (3 5 ADD HALT)

  []          → 3
  [3]         → 5
  [3, 5]      → ADD
  [8]         → HALT
  [8]         ← 停止。頂点 8、要素 1
```

ADD のあとに値が 1 つ残る。2 つ取って 1 つ戻すから、スタックの要素数は 1 減る。

## SUB とは

ADD と同じく 2 つ取る。計算だけが引き算である。

- 頂点が **b**（減数）
- その下が **a**
- 積む値は **a − b**（b − a ではない）

```
命令列: (5 2 SUB HALT)

スタックの変化:
  []          → 5
  [5]         → 2
  [5, 2]      → SUB（a=5, b=2, 5-2）
  [3]         → HALT
  [3]         ← 頂点 3
```

`(2 5 SUB)` なら 2−5 で −3 になる。順番を逆にすると結果が変わる。

## 末尾停止

HALT が無くても、pc が長さ以上ならフェッチ前に止まる。

```
命令列: (3 4 ADD)

  [] → 3 → [3] → 4 → [3, 4] → ADD → [7] → 末尾で停止
```

## 合格例

- `(3 4 ADD HALT)` → 頂点 7、要素 1
- `(5 2 SUB HALT)` → 頂点 3
- `(3 4 ADD)` → 末尾停止、頂点 7
